# v0.2.0 — Put channels in context.

`telegram fetch peer` tells you what a channel or group is about before you export its messages. Get its description, audience, and linked discussion group as JSONL, ready for a channel note or a closer look in fx. The new `indexit skill` commands give your coding agent instructions that travel with the binary.

## Turn channels into useful notes

```sh
indexit -q telegram fetch peer @example_channel @example_discussion \
  | jq '{uid, title, about, participants_count, linked_chat_uid, linked_chat, error}'
```

- Keep a channel’s description and member count alongside its identity and usernames.
- Pair it with the group that hosts its comments using `linked_chat_uid`, without guessing from titles. The group’s card points back to the channel.
- Get one card per reference, in input order. A failed reference carries an `error` so you can check partial results; users and bots return their identity with `not_channel`.

[Describe channels and groups →](/guide/peers/)

## Look at an invitation without joining

```sh
indexit -q telegram fetch peer 'https://t.me/+<hash>' | fx
```

- Replace `<hash>` with your invite’s hash. indexit inspects the invitation without joining the chat.
- Get a full card for a chat you belong to or may temporarily peek into. Otherwise, get Telegram’s preview with `invite_not_member` and no chat ID.
- See an expired or revoked invitation as `invite_expired`, alongside any other results in the same run.

[Explore invite previews →](/guide/peers/#preview-an-invitation-without-joining)

## Give your coding agent the matching skill

```sh
indexit skill install --agent claude-code,codex
indexit skill status --agent claude-code,codex --exact
```

- Install the bundled instructions offline for Claude Code or Codex, then start a new agent session. The skill helps the agent choose commands, handle Telegram links, and check incomplete exports; sign-in stays with you.
- After upgrading indexit, run `indexit skill install --agent claude-code,codex --replace`. It replaces only a copy installed by indexit that has not been edited.
- Use `skill status` to find incompatible or edited copies and `--exact` to detect content that differs from the bundled skill. Use `skill show`, `skill info`, or `skill export -o ./indexit-skill` to read, inspect, or copy it for another agent.
- Prefer a plugin manager? Stable releases also publish the skill to the OctoLab catalog.

[Set up your agent →](/guide/agents/)

## Use more Telegram addresses

- Paste `https://t.me/s/example_channel` preview links wherever a username is accepted.
- Resolve four-letter usernames as well as longer ones.
