# v0.2.3 — Every copy in sight.

`indexit skill status` now sees the skill when Codex installed it as a plugin, so you can check every copy your agents load, whichever way you installed them. `indexit telegram auth status` reports a configured proxy once instead of twice.

## Check Codex plugins

```sh
indexit skill status --agent claude-code,codex --exact
```

- Enabled Codex plugins named `indexit`, from any marketplace, are read from Codex’s `config.toml`, in `CODEX_HOME` when set.
- The copy checked is the one Codex itself loads: a `local` copy if there is one, otherwise the highest version.
- `--exact` passes when the plugin copy matches this release, and a Codex plugin now counts as a copy for the warning about several copies for one agent.
- If the plugin cache mixes version numbers with other names, which copy Codex loads depends on the order on disk: status names the directories, asks you to remove the stale ones, and `--exact` fails until you do.

## One proxy line

- `indexit telegram auth status` logs the configured proxy once, whether or not a session exists.

**Upgrade:** on macOS, run `brew update` followed by `brew upgrade --cask octolab/tap/indexit`. For a manual installation, use a [v0.2.3 release archive](https://github.com/octopot/indexit/releases/tag/v0.2.3). Run `indexit version` to check the installed version. If you use the agent skill, [replace it](/guide/agents/#keep-it-in-step) with the new binary’s copy.
