# v0.4.2 — A steadier line to Telegram.

indexit moves to a newer Telegram library: `telegram auth login --qr` signs in where it used to stall, and long exports and the photograph service keep their connection to Telegram.

## QR login that finishes

```sh
indexit telegram auth login --qr
```

- An account that Telegram keeps in another data center now finishes signing in after you scan the code, instead of stopping after the scan.
- The code on the screen is replaced reliably when it expires before you scan it.

[Explore authentication →](/guide/authentication/)

## A connection that stays up

- The connection to Telegram sends regular pings, so a long export or the photograph service, waiting between requests, keeps it open.
- When Telegram asks indexit to set up the connection again, it does so and goes on, instead of failing the request.
- A connection error that cannot pass by itself ends the command with that error, instead of retries that never succeed.

## Telegram compatibility

Updated Telegram protocol support to API layer 233.

**Upgrade:** on macOS, run `brew update` followed by `brew upgrade --formula octolab/tap/indexit`, then `brew services restart octolab/tap/indexit` if you run the photograph service. For a manual installation, use a [v0.4.2 release archive](https://github.com/octopot/indexit/releases/tag/v0.4.2). Run `indexit version` to check the installed version. If you use the agent skill, [replace it](/guide/agents/#keep-it-in-step) with the new binary’s copy.
