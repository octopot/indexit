# v0.3.0 — Photos that stay.

Exported photo messages now carry permanent local URLs. indexit's own image service on your Mac saves each photograph the first time it is opened and keeps showing it in your notes, even after the post, the channel or your Telegram session is gone. The CLI and the service install together as one Homebrew Formula.

## Photographs in your notes

- `fetch messages` and `fetch message` add `media.preview_url` to ordinary photo messages, pointing to `http://indexit.localhost:17840/`. Put it in a Markdown note as an image source.
- An album lists every photograph in `media.album.photos`, even when you select one item in the middle; `complete` and `error` tell you whether the album is whole.
- The first request downloads the largest version of the photograph and saves it in `~/.local/share/indexit`. From then on it shows without Telegram or the network.
- Writing a URL needs no running service and downloads nothing. When a photograph can't be stored, `media.preview_error` says why and the caption stays.

[Set up the image service →](/guide/local-images/)

## A service with no setup

- `brew services start octolab/tap/indexit` runs the service as your user. It listens only on this Mac, at `127.0.0.1:17840` and `[::1]:17840`.
- `.localhost` names always mean this Mac: no hosts entry, no sudo, no network settings.
- `indexit service run` starts it by hand, on Linux too; a repeated `--listen` replaces the default addresses with your own loopback ones.
- `origin` under `[service]` in `~/.config/indexit/config.toml` sets another origin for new URLs. An unknown key or a malformed origin stops the command with an error naming the file and the key.

## Notes from your agent

- Ask your coding agent to save a post as a note: the agent skill embeds the post's photographs from the image service and opens each one once, so the copy is kept.

[Teach your agent indexit →](/guide/agents/)

## One Formula

- indexit is now the Homebrew Formula `octolab/tap/indexit`: the CLI and the service in one package that updates together. The Cask is no longer updated.

## Known limitations

- Videos, GIFs, documents, web previews, paid and expiring media get no URL.
- URLs work on this Mac only, not from a phone or another machine.
- On Linux, the service doesn't install itself; run `indexit service run`.

**Upgrade:** on macOS, run `brew update`, then switch from the Cask once: `brew uninstall --cask octolab/tap/indexit` and `brew install --formula octolab/tap/indexit`. Don't add `--zap`: keep your Telegram configuration and saved photographs. Later upgrades are `brew upgrade --formula octolab/tap/indexit`. For a manual installation, use a [v0.3.0 release archive](https://github.com/octopot/indexit/releases/tag/v0.3.0). Run `indexit version` to check the installed version. If you use the agent skill, [replace it](/guide/agents/#keep-it-in-step) with the new binary’s copy.
